# Palavra Secreta — página de vendas low ticket

Página de vendas (um único `index.html`, sem dependências) para um infoproduto cristão de baixo ticket, **posicionado como bem-estar e saúde mental**: ansiedade, pensar demais, noites mal dormidas. A fé é o *mecanismo* (“a palavra certa”), não a etiqueta. Assim o anúncio alcança tanto quem é cristão quanto quem está “buscando algo”, sem parecer nichado.

## Como usar
1. Abra `index.html` e edite o bloco `CONFIG` no final do arquivo:
   - `checkoutUrl`: link do checkout (Kiwify, Hotmart, Eduzz, Cakto…)
   - `price` / `fromPrice`: preço e valor de ancoragem
2. Troque os 3 depoimentos de exemplo (`#depoimentos`) por **depoimentos reais**. Enquanto não tiver, apague a seção — nunca publique depoimento inventado.
3. Suba em qualquer hospedagem estática: GitHub Pages, Netlify, Vercel ou Cloudflare Pages.

UTMs do anúncio (`utm_*`, `src`, `sck`) são repassadas automaticamente para o checkout.

## A oferta (por que tende a vender bem)
| Peça | O que é |
|---|---|
| Produto principal | Diário de 30 dias, 5 min/dia (ler → refletir → praticar) |
| Bônus 1 | Noites em Paz — 7 orações/meditações para dormir |
| Bônus 2 | Kit de Emergência da Alma — cartões para crises |
| Bônus 3 | Planner de Gratidão e Propósito |
| Preço | R$ 19,90 pagamento único (faixa ideal: R$ 9,90–27,90) |
| Garantia | 7 dias (direito de arrependimento do CDC) |

Sugestões de funil para aumentar o ticket médio:
- **Order bump (R$ 9,90):** “Versão em áudio — ouça os 30 dias no caminho para o trabalho”.
- **Upsell (R$ 37–47):** “Palavra Secreta para Casais” ou “Para Mães” — 30 dias focados em relacionamento/família.
- **Downsell (R$ 19,90):** só o Kit de Emergência + Noites em Paz.

## Ângulos de anúncio que não parecem nichados
- “Se sua mente não desliga na hora de dormir, faça isso por 5 minutos.”
- “A frase de 2 mil anos que psicólogos chamam de ‘técnica de foco no presente’.”
- “Pare de pensar demais: o ritual de 5 minutos que mudou minhas manhãs.”
- Público de presente: “O presente mais barato e mais significativo que você vai dar este ano.”

> Observação: o material é de apoio emocional/espiritual e a página já avisa que não substitui acompanhamento médico ou psicológico — mantenha isso nos anúncios também (evita bloqueio no Meta Ads).
